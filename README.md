## About

SOC analyst who researches attacker techniques and turns them into detections, scripts, and write-ups. I focus on how attacks show up in logs and how to detect them reliably, mapped to MITRE ATT&CK.

## What I work on

- **Detection rules:** Sigma and Splunk SPL detections for real attack techniques
- **Security research:** reproducing techniques in isolated labs and documenting the telemetry they leave behind
- **Scripts and tools:** Python utilities for log analysis, IOC extraction, and analyst workflows
