## About

SOC analyst who researches attacker techniques and turns them into detections and write-ups. I focus on how attacks show up in logs and how to detect them reliably, mapped to MITRE ATT&CK.

## What I work on

- **Detection engineering:** Sigma and YARA rules validated through adversary emulation (Atomic Red Team) and Splunk detections, contributing back to SigmaHQ
- **Security research:** vulnerability analysis and TTP research, reproducing techniques in isolated labs and documenting the telemetry they leave behind
- **Malware analysis:** static and dynamic analysis of samples with detection-focused reporting
